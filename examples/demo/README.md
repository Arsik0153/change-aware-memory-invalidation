# Synthetic example

All expected child labels were authored from the fixture scenario, independently of the AST validator. This is not a real research dataset.

In a fresh clone, restore the bundled Git history with `git clone examples/demo/repo.bundle examples/demo/repo`. Then use `uv run cami check-inputs --config examples/demo/run.json`.

The demo command creates a separate equivalent fixture in its output directory and needs no setup of this example.
