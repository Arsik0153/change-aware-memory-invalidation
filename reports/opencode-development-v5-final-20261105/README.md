# OpenCode + CAMI: завершённая серия разработки v5

Все 36 решений прошли фиксированные acceptance- и regression-тесты. Технически
успешны 35 запусков: `r3-static-s1` сохранил статус `failed`, поскольку проверка
формата отвергла служебное сообщение OpenCode типа `system` при смене даты на
5 ноября. Сама сессия и тесты
прошли; затраты этого запуска полностью включены. Повторов взамен неудач и
исключённых строк нет. **Преимущество CAMI по заранее принятому критерию не
установлено.** Работа остановлена по просьбе пользователя после завершения серии.

## Наблюдаемые затраты

Каждая строка — полная последовательность четырёх этапов на двух задачах одного
режима, включая
построение, проверку и обновление памяти. Оба показателя ниже только описательные:
техническая ошибка одного запуска не позволяет заявить первичное преимущество.
Даже без этой ошибки ни один показатель не удовлетворяет всем шести парным
сравнениям CAMI с двумя альтернативами.

| Повтор | Режим | Полное учитываемое время, с | Нормализованные токены без чтения кеша |
|---|---|---:|---:|
| 1 | OpenCode | 526.82 | 152646 |
| 1 | Память без CAMI | 538.75 | 120680 |
| 1 | Память с CAMI | 570.97 | 124453 |
| 2 | OpenCode | 546.72 | 133380 |
| 2 | Память без CAMI | 521.53 | 149665 |
| 2 | Память с CAMI | 561.69 | 123125 |
| 3 | OpenCode | 544.03 | 120897 |
| 3 | Память без CAMI | 569.49 | 126291 |
| 3 | Память с CAMI | 568.80 | 116935 |

CAMI использовал меньше нормализованных токенов, чем обычный OpenCode, в трёх
повторах, но был медленнее в каждом. Против статической памяти результат смешанный:
два выигрыша из трёх по токенам, один из трёх по времени. Эти числа не являются
ценой подписки: счётчик равен `input + cache.write + output + reasoning`; чтения
кеша приведены отдельно в полном отчёте. Реальные счета провайдера недоступны.

Локальный CPU контейнеров за четыре этапа составил 55.69–57.85 с для OpenCode,
56.02–58.88 с для статической памяти и 67.14–69.40 с для CAMI. Максимумы памяти
контейнеров CAMI — 451.1–456.1 МиБ; конечное хранилище CAMI — около 27.7 МиБ,
статический каталог — около 0.8 МиБ. Это cgroup-память, а не только RSS, и
логические размеры файлов в границах этапов, а не непрерывный максимум диска или
стоимость аренды хранилища. Полные определения и ограничения сохранены в отчёте
ресурсов. Эти данные не выделяют конкретный вычислительный участок, оправдывающий
переписывание на Rust.

## Устаревшие сведения

[Отдельный анализ точных литералов](staleness/report.json) охватывает все 36
завершённых испытаний, включая технически неуспешное. Неподдерживаемых вызовов
в этом анализе нет. CAMI вернул 48 наблюдений совпадающих литералов и скрыл 12
устаревших; статическая память вернула 48 совпадающих и 12 устаревших.
Эти 12 наблюдений относятся к двум уникальным записям и не являются
12 независимыми случаями. Сравнивались точный
префикс определения Python до 2400 символов и признак усечения; равенство всего
тела, поведения программы или причинное использование моделью не выводились.
Разметка видимого использования устаревших сведений ещё не выполнена.

## Условия и воспроизводимость

OpenCode 2.2.5, одна модель `openai/gpt-6.1-sol#high`, одинаковые настройки,
лимиты, два заранее закреплённых исторических задания Click и версии исходников.
Три режима, три повторения, четыре этапа: первое обращение, повтор, другая задача
после канонического изменения кода, повтор. Каждая сессия OpenCode новая; память
сохраняется внутри последовательности режима. Предыдущие решения модели не
становятся входом следующей задачи. Удалённый кеш и веса модели клиент не
фиксирует; исторические публичные задачи могли присутствовать в обучении.

Во время серии не запускались наши дополнительные тесты, упаковка или параллельные
модели. Совпадение всех закреплённых исходников и входных файлов повторно проверено
после завершения. Проверены 36 terminal-файлов и 8094 заявленных ими артефакта.
В первичном анализе нет исключений и неизвестных метрик. Сырьевые публичные журналы,
фиксация реализации, результаты и воспроизведение агрегирования сохранены в
`publication/`; финальное состояние памяти — отдельным необязательным архивом.
Авторизационные данные и приватное состояние OpenCode не публикуются.

Время построения памяти, работы сессии, проверок и обновлений включено в показатель
`charged_host_wall_seconds`. Каноническая подготовка задач, экспорт и внешний
фиксированный оценщик приведены отдельно как инфраструктура эксперимента;
вложенные интервалы не складываются повторно. Анализ и упаковка после завершения
не прибавляются к измеренным затратам агента. Сведения о ресурсах удалённого
провайдера недоступны. Это завершённый набор разработки, а не итоговая проверка.

## Где продолжить позже

1. Учесть типизированные служебные сообщения закреплённого API OpenCode, включая
   `system`, сохраняя строгую проверку содержимого и согласование реальных вызовов.
   Проверять на полных, нефильтрованных журналах; исходный результат v5 не менять.
2. Профилировать проигрыш CAMI по времени на наборе разработки. Не выбирать
   реализацию по итоговым задачам и не переписывать код на Rust без подтверждённого
   вычислительного узкого места.
3. Завершить разбор видимого использования устаревших сведений по закреплённому
   протоколу; AI-разметку не называть человеческой.
4. После завершения разработки отдельно заморозить реализацию и анализ для
   итогового набора. Запусков моделей на итоговых задачах пока **0**.

Исторические серии v1–v4 и неудачные прототипы сохранены отдельно. Результаты v5
с ними не объединяются. Новые эксперименты при закрытии этой серии не запускались.
