# Test of the source-prefix premise

Premise: fixing display or explicit-symbol selection makes cached source prefixes
sufficient to reduce agent navigation and model work. The completed format and
ranking blocks did not establish this. A new ranking tweak is not justified by
identifier coverage alone.

The rerunnable memory_read_overlap.py checks all closed ranking trials and counts
only exact logical-text prefixes in later reads of the same file, after the
memory call completed. Both CAMI conditions have six reads containing a full
previously returned prefix, all before the first explicit patch/write/edit. Those
reads may also contain necessary new information; overlap is not avoided work.
Shell mutations are outside the explicit-edit boundary. Redacted text is unknown.

Only16 record observations were returned per CAMI condition. The candidate made
59 reads and54 assistant messages, versus46 reads and49 assistant messages for
lexical CAMI. Most work is outside direct duplicate-prefix readings. The evidence
does not determine the model's intent, nor prove that larger excerpts would help.

Next intervention: separately evaluated exact-input result memory, with empty
cache, first-solution costs, strict changed-input misses and mandatory fresh
grading. This tests actual reuse of performed work, with a deliberately narrow
claim about repeated identical tasks. No prior solution enters its fresh run.
