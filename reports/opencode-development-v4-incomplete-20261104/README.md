## Воспроизводимость

`retrospective_grade.py` — реально выполненный одноразовый драйвер; повторно использует только новый `evidence/` и не перезаписывает существующий. `pack_public_archives.py` — сборщик неизменяемых архивов; требует отсутствующий `archives/`. Не запускайте их в этом завершённом output-каталоге повторно. Для повторения используйте новую рабочую копию/новый output с явными теми же входами и тихим окном. У исполненного grade-драйвера оставлен неиспользованный импорт `hashlib`, чтобы не менять байты архивированного исполненного исходника; Ruff отмечает только этот F401.
