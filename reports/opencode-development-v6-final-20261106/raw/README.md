Public raw means exact already-sanitized events/messages/tool traces and artifacts, not unsanitized provider/auth/private state.

Full mutable namespace workspaces/Git, all OpenCode auth/private state, heldout assets, images/binaries/credentials and unrelated old archives are excluded. Ordinary single-link files only; safe modes, no symlinks/special/privileged files. Known credential-shaped structured/text fields are refused. Published bytes are copied exactly; no new transcript redaction or missing-evidence repair occurs. These are bounded publication checks, not arbitrary encoded-secret detection.

Every archive has an internal SHA256/size/mode manifest, deterministic gzip/tar metadata, a matching second build and a fully verified extracted copy. All admitted originals are rehashed afterward. Source versions are checked against the140-file pre-run frozen archive; current bytes are used only when matching those exact hashes, otherwise exact frozen bytes are recovered with explicit provenance. Storage must stay above5GiB; partial failures are preserved, never overwritten.
