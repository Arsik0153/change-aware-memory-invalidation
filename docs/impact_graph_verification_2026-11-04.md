# Ограниченная исчерпывающая проверка распространения изменений

Алгоритм `cami.index.impacted` сопоставлен с отдельным эталоном кратчайших путей
на 208896 конечных случаях. Расхождений нет. План закреплён в f794b87,
проверяющий код — в 651ef29; production алгоритм не менялся.

## Что проверено

Для трёх узлов перебраны все 512 ориентированных графов, включая петли.
Для четырёх узлов — все 4096 ориентированных графов без петель, с циклами
произвольного допустимого вида. В каждой группе взяты все подмножества
изменённых узлов, включая пустое, и все разрешённые глубины 0, 1, 2.
Итого `512 × 8 × 3 + 4096 × 16 × 3 = 208896` проверок.

Первый узел обозначает файл `module.py`, остальные — разные функции в нём.
При любом изменении файл также входит в начальное множество затронутых узлов,
как предусмотрено интерфейсом ChangeSet. Поэтому проверяются и file-level nodes,
и различение функций одного файла. Отсутствие изменений не порождает affected nodes.

Production использует обратное распространение по рёбрам. Отдельный oracle
вычисляет матрицу всех кратчайших направленных путей алгоритмом Floyd–Warshall.
Потребитель затронут, если может дойти до изменённой зависимости за не более
заданного числа рёбер. Сравниваются полные множества Node, а не только их размеры.

Отрицательный контроль на одном направленном ребре отдельно проверяет,
что искусственная перестановка source и target даёт несовпадение с oracle.
Сам oracle дополнительно сверён на цепочке длины три, цикле и изолированной петле.

## Границы вывода

Это ограниченная проверка реализации, не математическое доказательство для
графов любого размера. Она не проверяет parser, union графов двух ревизий,
истинность claims, другие fallback в select_claims или полноту provenance.
208896 случаев не являются независимыми наблюдениями магистерского эксперимента;
для них не вычисляются доверительные интервалы или частоты ошибок в популяции.
Повторение не даёт оснований снимать known_incomplete или допускать held-out cohort.

Снимки исходников до/после совпали. Protocol, results и manifest с hashes:
`reports/research-20261104/impact-graphs-v1/`.

```bash
.venv/bin/python -m scripts.check_impact_graphs \
  --out reports/impact-graphs-NEW
```

Нужна установленная среда проекта и чистые закоммиченные исходники.
Docker, сеть и платные API для этой проверки не используются.

Количество 208896 считает перечисленные входные комбинации, а не уникальные
семантические множества seeds: явное изменение file node иногда совпадает с его
неявным добавлением из changed files. После объединения таких seeds получаются
`512 × 5 × 3 + 4096 × 9 × 3 = 118272` различных комбинаций graph/depth/seed set.
Повторные эффективные seeds не добавляют независимой доказательной силы.
