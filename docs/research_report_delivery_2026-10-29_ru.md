# Как читать и воспроизвести отчёт CAMI от 29 октября 2026 года

Основной документ — `CAMI_research_progress_2026-10-29.pdf` (7 страниц).
Редактируемая версия — одноимённый `.docx`. `report.md` содержит тот же текст
и относительные ссылки на два графика в `assets/`. `source-original.md` сохраняет
исходный Markdown с путями относительно репозитория CAMI.

Это предварительные научные результаты разработки, а не итог основного
held-out эксперимента. Независимые человеческие ответы и допуск реальных
данных ещё не получены. Техническая перепроверка отдельной моделью не заменяет
разметчика или научного руководителя.

## Что входит в пакет

- DOCX, PDF, обе Markdown-версии и два исходных PNG-графика.
- `evidence/`: 20 компактных файлов результатов, проверок и журналов.
- `manifest.json`: версия сборщика, исходные hashes, зависимости и hashes
  файлов сборки. Статус `rendered_pending_visual_review` фиксирует момент
  окончания автоматической сборки; последующая проверка находится в `verification/`.
- `text-check.json`: сверка 118 абзацев и ячеек с текстом PDF.
  `extracted.txt` сохраняет расположение; `extracted-raw.txt` сохраняет порядок
  текстового потока для многострочных таблиц.
- `verification/visual-review.json`: осмотр всех семи страниц и тождество
  изображений страниц двух сборок.
- `verification/independent-review.json`: отдельная техническая проверка
  чисел, утверждений и целостности файлов.
- `package-files.json`: SHA-256 каждого файла архива, кроме самого списка.

Пакет не содержит всех исходных raw runs, Git-корпусов, Docker images и
полного кода CAMI. Полное повторение экспериментов требует репозитория и
входов, указанных в соответствующих исследовательских документах. Пути E1–E9
в PDF заданы относительно корня репозитория, а не относительно архива.
В `evidence/` сохранена выбранная часть источников по тем же именам каталогов.
Проверка hash устанавливает целостность относительно сохранённого списка;
сама по себе она не доказывает истинность научного утверждения.

## Проверка извлечённого архива

Из корня распакованного пакета выполните Python-команду:

```python
import hashlib
import json
from pathlib import Path

root = Path.cwd()
expected = json.loads((root / "package-files.json").read_text())
actual = {
    p.relative_to(root).as_posix(): hashlib.sha256(p.read_bytes()).hexdigest()
    for p in root.rglob("*")
    if p.is_file() and p.name != "package-files.json"
}
assert actual == expected, "Состав или содержимое пакета изменились"
print(f"Проверено файлов: {len(actual)}")
```

SHA-256 самого ZIP и результат проверки CRC сохранены отдельно в репозитории:
`reports/research-20261029/report-build-v2/package-audit.json`.

## Повторение сборки документов

В репозитории CAMI нужны Python 3.12, локальные LibreOffice и Poppler
(`pdftotext`), шрифты Liberation. Зависимости устанавливаются в отдельную среду:

```bash
python3.12 -m venv runs/report-tools
runs/report-tools/bin/pip install -r requirements/report.txt
runs/report-tools/bin/python -m scripts.build_research_report \
  --out output/research-progress-new
```

Каталог результата должен быть новым, а отслеживаемые исходники — закоммиченными.
Сборщик проверяет входы до и после работы. После сборки необходимо осмотреть
все страницы PDF; успешная сверка текста не обнаруживает все ошибки оформления.
DOCX/PDF могут отличаться побайтово из-за времени создания и версии рендерера.
Условия и зависимости фактической сборки записаны в `manifest.json`.

Первая сборка сохранена как failed: режим `pdftotext -layout` перемешивал строки
соседних ячеек и дал три ложных сообщения об отсутствии текста. Во второй
сборке изменён только способ проверки текста; все семь изображений страниц
совпадают. История проверки находится в `reports/research-20261029/report-build-v1/`.
